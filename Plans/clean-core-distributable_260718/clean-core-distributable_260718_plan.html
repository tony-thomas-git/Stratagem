Clean Board-Blind Coder Distributable

A self-contained sg-only plugin marketplace — keep the neutral board/chat seam, ship no adapters.
Type · Feature Plan (PF) Repo · Stratagem @ tt/strat-dist Date · 2026-07-18 Tracer Bullet · YES (validate a standalone sg install before carving) Est. scope · ~12–18 files across 5 phases + 1 cross-repo touch Identity · marketplace Stratagem · namespace /sg: Next · /cp

1 · Goal

Turn the Stratagem distribution repo into a clean coder-flavored plugin marketplace that ships the workflow engine (sg) alone — complete and runnable with zero external dependencies — while retaining the neutral lifecycle seam so any external board or chat system can attach later via a presence-checked adapter. No concrete adapters (stratagem-ado, stratagem-teams) ship in this build, and core names no external system.

The good news, up front: the board-sync capability is already board-blind and lives in core (/ax emits a neutral {event,syncId,task} signal; /if resolves boardSync by presence-check; autonomy-loop.js carries boardNotify). Keeping sg keeps the capability. This feature is packaging + purity, not building a new seam.

3 · Target architecture

One marketplace, one shipped plugin (sg), two neutral seams that resolve to externally-installed adapters by presence-check. The dependency arrow points only inward (adapter → core), never out.

Reading: adapters resolve into core's seams when installed+enabled; with none present every emit is a silent no-op (the write-only events.log trace still records). Adapters remain installable from the canonical stratagem-core marketplace — this build simply omits them.

7 · Risks & open edges

  • H Cross-repo contract skew. Renamed headers must be understood by the canonical adapter or synced plans break. Mitigation: D3 back-compat, and the re-attach test as the gate.
  • M Source-of-truth ambiguity (D5). If edits land here and upstream, they diverge. Resolve D5 before Phase 1/3.
  • M Vault coupling. Vault/ado-board-config.md rename touches a vault file → the mandatory CHANGELOG.md entry + fleet-check apply.
  • L Namespace identity. Only one sg installs at a time; dev iteration = uninstall+reinstall (version-keyed cache).

8 · Out of scope

  • Publishing / pushing the marketplace anywhere — packaging only; distribution channel is a later call.
  • Rewriting the two CLAUDE.md vault schemas (a separate, already-flagged follow-up).
