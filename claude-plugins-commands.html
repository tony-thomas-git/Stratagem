Claude Code Plugin Commands

Install & manage the Stratagem distribution and its research add-on.
repo · tony-thomas-git/Stratagem marketplace · stratagem core plugin · sg add-on · stratagem-tavily

Quick start — clean machine

claude plugin marketplace add tony-thomas-git/Stratagem
claude plugin install sg@stratagem                 # then restart Claude Code
claude plugin install stratagem-tavily@stratagem
claude plugin enable  stratagem-tavily@stratagem
# in Claude Code:  /stratagem-tavily:setup   → paste your Tavily key, then restart

Private repo? Grant the person collaborator access on GitHub, and have them run gh auth setup-git (or set up an SSH key) once first.

Marketplace

claude plugin marketplace add tony-thomas-git/StratagemAdd the marketplace (GitHub shorthand — uses SSH by default). Reads .claude-plugin/marketplace.json at the repo root.
claude plugin marketplace add https://github.com/tony-thomas-git/Stratagem.gitAdd via explicit HTTPS URL (uses your git credential helper).
claude plugin marketplace add git@github.com:tony-thomas-git/Stratagem.gitAdd via explicit SSH URL (uses your SSH key).
claude plugin marketplace add C:\code\StratagemAdd from a local clone — handy for testing before publishing.
claude plugin marketplace update stratagemRe-pull from GitHub to pick up new commits.
claude plugin marketplace remove stratagemUnregister the marketplace — e.g. to clear a name collision.

Plugins

claude plugin install sg@stratagemInstall the core workflow engine. Auto-enables — restart Claude Code to register /sg:*.
claude plugin install stratagem-tavily@stratagemInstall the research add-on. Ships disabled.
claude plugin enable stratagem-tavily@stratagemActivate the add-on.
claude plugin disable stratagem-tavily@stratagemDeactivate it (keeps it installed).
claude plugin update stratagem-tavily@stratagemPull a newer version (only picks up a bumped version).
claude plugin uninstall stratagem-tavily@stratagemRemove it. Uninstall + install is the reliable force-refresh when a cached version won't update.

Validate & verify

claude plugin validate .Official pre-publish structure check — run from the repo root. Catches schema errors, duplicate names, bad source paths.
claude mcp listConfirm the Tavily MCP (plugin:stratagem-tavily:tavily) shows connected.

Private-repo auth (once per machine — git, not Claude)

gh auth setup-gitSimplest — writes a GitHub token into git's credential helper (HTTPS).
ssh -T git@github.comSSH route — trust the host once. Needs an SSH key on your GitHub account.

Inside Claude Code (slash commands, not the CLI)

/plugin marketplace add tony-thomas-git/StratagemSame as the CLI, from within a session.
/helpConfirm /sg:* and /stratagem-tavily:setup registered.
/stratagem-tavily:setupOne-command Tavily key setup — prompts for the key (or pass it inline) and writes the config file for you.

Env vars (private-repo edge cases only)

CLAUDE_CODE_PLUGIN_PREFER_HTTPS=1Make the owner/repo shorthand use HTTPS instead of SSH.
CLAUDE_CODE_PLUGIN_KEEP_MARKETPLACE_ON_FAILURE=1Keep the working clone if a background auto-update pull fails.

Env-var names can be version-dependent — the reliable core is collaborator access + gh auth setup-git (or SSH). SSH is the most trouble-free for a private marketplace.
