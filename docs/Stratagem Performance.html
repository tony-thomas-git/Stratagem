Where the ~61 s/agent goes — three sinks

#SinkWhy it costs
1 Sequential execution of independent tasks All 5 tasks are Depends on: Nothing (leaf), yet the loop ran them strictly serially — and stages within a task (px → ax → verify → board-sync) are serial too. Nothing parallelized. For 5 independent tasks this is the obvious ~5× left on the table.
2 Per-agent cold-start tax (CORPUS-READ-FIRST + skill load) Each fresh agent re-loads from scratch: its full SKILL.md (300+ lines), the plan file, and the CORPUS-READ-FIRST chain — resolve vault → read Steward\CLAUDE.md (~36 KB ≈ 9k tokens) → open vault index → drill pages. Repeated ~10×. This is why 5 five-byte files cost 413k tokens — almost all input from re-reading the same big files in new contexts. Loading + reasoning over those prompts is real latency, not just tokens.
3 Live ADO round-trips board-sync drove New→Active→Resolved ≈ 2 MCP writes/task ≈ 10 calls to Azure DevOps through the npx-launched server. Real but minor next to #1 and #2.
